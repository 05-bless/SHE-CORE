# SHE CORE

## Smart Health and Emergency Response Core

SHE CORE is a smart wearable safety and health monitoring system designed to provide rapid assistance during emergencies involving women and elderly users.

The system combines health monitoring, motion/fall detection, location tracking and emergency communication into a single wearable platform.

## Key Features

- Heart-rate and SpO₂ monitoring
- Fall detection
- Motion monitoring
- GPS-based location tracking
- GSM-based emergency alerts
- Sensor-fusion based emergency assessment
- Intelligent alert decision logic
- Emergency notification to predefined contacts
